Forth 2012 Standard — Library reference for Ask Forth
=====================================================

These plain-text chapters are derived from the official Forth-2012 HTML
package (Forth 200x / forth-standard.org, November 2014 snapshot from
complang.tuwien.ac.at). They are included so Ask Forth Library context can
quote stack effects and word meanings from the standard.

Browse the interactive standard at: https://forth-standard.org/

When "Include Library context" is on, EditForth also searches this Reference
folder even if Library… points at Sample (or another subfolder).

Forth-2012-word-urls.json maps standard word names to forth-standard.org
paths for Ask Forth’s “Fetch URLs in Prompt” auto-boost (live page fetch).

Stack-effects-cheatsheet.txt is a short Ask Forth helper for stack comments
and idioms models often invent wrong (MOVE/COMPARE/TYPE/files/records). It is
indexed with the other Reference text; do not INCLUDE it.

Not Forth source — do not INCLUDE these files into the dictionary. Also copy
updates into ~/Documents/EditForth/System/Reference/ for the live tree.
